# SmartTools Tabs Importer / 书签管理客户端

保留原有标签页导入，并提供内置浏览主页与独立的 SmartTools 轻量书签管理页（v1.2.0）。不接管 Chrome/Edge 新标签页，不读取浏览器原生收藏夹。

## 安装与连接

1. 将配套服务端更新到支持 `GET /api/data?format=structured` 和版本保存检查的版本。
2. 浏览器扩展管理页开启开发者模式，加载本目录 `extensions/open-tabs-importer/`。更新后点击“重新加载”。无需构建扩展；全部脚本随目录本地提供。
3. 打开弹窗，填写自己的 HTTPS 后台地址（如 `https://your-site/config.html`）；本机开发允许 HTTP localhost。
4. 点击“保存地址”或导入时，仅授权该站点。也可点击“书签管理”，在独立页面内“授权并连接”。
5. 使用现有单管理员账号在插件内登录，或复用同一浏览器配置中的网站会话。

## 独立主页

- 左侧分组与数量、Private/隐藏标识；顶部搜索、刷新、显式“保存到云端”。
- 分组增删改、上下排序；书签和子卡片增删改、排序、跨组/层级移动；搜索标题、链接、描述、备注和子卡片。
- 所有修改先保存在当前页面内存，关闭/刷新有未保存提醒。删除非空分组须选择迁移或全部删除。Private 转为公开或跨组公开需再次确认。
- 特殊分组/卡片保留原数据并只读展示；备份、恢复、站点配置、复杂批量整理继续使用完整后台。
- 图片/相对链接按配置的 SmartTools 站点解析。内联 SVG 不作为 HTML 注入（安全占位显示，原始值保留）。
- 未绑定 KV 时只读。静态数据第一次保存须确认完整初始化到 KV；旧服务端、断网和不支持的源码会明确报错。

## 登录与安全

沿用站点 HttpOnly、Secure、SameSite=Strict、HMAC 校验 Cookie；扩展不读 Cookie，不保存密码、token。退出会影响同浏览器同站点的网站会话。会话失效、退出、权限撤销时撤销云端写入状态，但保留本机缓存；重新激活页面检查会话。

Cookie 限制可能使插件登录不可用。请检查站点授权/浏览器第三方 Cookie 策略，或直接在完整后台继续；网站登录不保证能绕过扩展请求的 Cookie 限制。

保存携带 `baseEtag` 和 `baseSource`。409 冲突会保留草稿并停止，不自动全量覆盖；刷新前请核对/手工保留更改。KV 最终一致，这不是原子 CAS/事务，请避免多入口同时保存。没有离线编辑队列。

保存故障处理：分类增量先在内存生成最终内容，再统一写入 KV，避免同一次保存对相同键重复写入。存储异常返回 JSON `503 / SAVE_STORAGE_ERROR` 与 `outcomeUnknown: true`，不冒充登录失败；这不提供事务或跨请求限流保证。扩展仅在服务器确认 401／会话失效时撤销登录状态；网络超时、网关 403/5xx 和权限撤销单独显示连接异常／暂时只读，保留草稿及上次验证的身份，不自动重试。账户面板的“检查连接与云端（保留草稿）”可重新核对，刷新丢弃草稿仍需确认。错误提示包含接口与 HTTP 状态，不记录密码、Cookie 或书签内容。


## 原有标签页导入

弹窗保留“收藏当前页”“导入当前窗口”“导入全部窗口”、复制 JSON/文本、导出 HTML/JSON。标签仅含 HTTP(S) 页面的标题、URL、图标地址；排除后台自身。后台未打开时暂存在 `chrome.storage.local`，打开配置页后重试投递；后台确认接收后清除待导入记录。最终仍需在网站后台确认并保存。

“打开后台”进入网站；“书签管理”打开/复用扩展本地页面。只在授权的配置页注册 `pending-import.js`，不再在所有网页注入。

## 权限和存储

- `tabs`：用户操作时读取当前或批量标签信息，并打开/复用页面。
- `scripting`：仅在授权的配置页投递导入内容、注册待导入脚本。
- `storage`：`sync` 保存站点地址（浏览器开启同步时可能随账号同步）；`local` 保存待确认导入及按站点选择的分类键等界面偏好，不保存完整管理员书签。
- `optional_host_permissions`：声明 HTTP(S) 可选域名范围以支持自部署，运行时只请求用户配置的站点；没有必需的 `<all_urls>`。
- 不使用 `cookies`、`bookmarks`、`history` 权限。历史已授权站点可在浏览器扩展设置中撤销。

## 验收

本地 Pages 使用隔离 KV 后执行 `npm run test:api`、`npm run test:browser`、`npm run test:extension`；纯内存检查可单独运行 `npm run test:extension-data`。

扩展浏览器脚本使用 Playwright Chromium；可用 `EXTENSION_CHROME_PATH` 指定支持命令行加载扩展的 Chromium。测试真实加载 MV3 脚本，不 mock 登录或 Cookie；因为 headless 无法点击浏览器原生站点权限气泡，会在 `.wrangler/` 的临时 manifest 中仅预授权 loopback 测试站点。原始 manifest 的最小权限另行断言。原生授权/拒绝/撤销、严格第三方 Cookie 策略及不同 Chrome/Edge 版本仍需手工验证。测试产物不发布。

## 共享长期缓存与右键收藏（1.2.0）

管理页右上角未登录时显示“登录”，登录后显示管理员头像；点击打开账户弹层，统一查看登录状态、站点授权、登录／退出、同步时间和缓存管理。点击外部或按 Esc 关闭，关闭时清空尚未提交的密码。退出不清除缓存、清除缓存不退出会话的规则不变。

完整管理员数据（含 Private）按站点保存到扩展自身来源的 IndexedDB，浏览主页、管理页与右键菜单共用；不设主动过期时间，不随浏览器账号同步，不宣称加密。退出、会话过期、断网或撤销权限后仍可查看本机副本，服务器无法撤回已下载内容；“清除当前／全部站点缓存”独立于退出，清除也会丢弃相关页面草稿。卸载、浏览器清理或存储故障可能丢失缓存。密码和 Cookie token 不持久化；未保存草稿仅在各页面内存中。

右键网页、链接或扩展图标 → 收藏到 SmartTools → 分组 → 独立卡片／已有展开卡片的子卡片。Private、隐藏分组仍显示并带标识；普通卡片不会自动变为父卡片。链接无标题时使用 URL；仅接受 HTTP(S)。无缓存显示“登录／加载收藏位置”，根入口始终存在。

每次收藏重新鉴权、获取最新完整数据、核对稳定目标和 Private 属性；同位置完整 URL 重复跳过，不同位置允许重复。串行提交分类增量，冲突保留现状、不重试、不回退全量覆盖。静态初始化只在管理页 `home.html` 确认，无 KV 不能保存。角标及原弹窗显示结果。

打开主页／弹窗先展示缓存再校验会话与云端版本，无变化不下载完整数据，无定时轮询；登录／刷新／版本变化更新共享缓存。无草稿管理页自动跟随，有草稿则提醒核对。内容脚本及网页无权调用缓存接口；站点切换保留旧站点的隔离缓存。

新增权限仅 `contextMenus`，不新增 alarms、unlimitedStorage、cookies、bookmarks、notifications。手工验收应覆盖原生三级菜单、角标、权限撤销、共享设备退出后可见 Private 的明确告知。自动化只用合成数据。

共用设备请“退出登录”并“清除本机缓存”：二者独立，清缓存不终止服务器会话；仍登录时，下次联网加载可重新缓存。

## 内置浏览主页与列表管理（扩展 v1.2.0）

扩展弹窗保留 **打开主页**（`start.html`）与 **书签管理**（`home.html`）两个入口，不接管新标签页。主页改为 iTab 风格标准图标桌面：56px 分类侧栏、居中时钟/日期/本机搜索、60px 图标、单层文件夹浮层。390px 四列、320px 三列，窄屏通过分类按钮打开侧栏。隐藏组不显示且不参与搜索；已缓存 Private 退出或离线仍可查看。搜索显示分类/文件夹路径；父卡片主链接单独保留，普通链接新标签页打开，特殊类型只读保留。

主页支持右键、可见更多按钮及 Shift+F10 菜单，新增/编辑/删除分组、书签和文件夹；鼠标左键拖动排序、跨组移动和安全叶子书签移入/移出文件夹。普通书签互拖只排序，不合成文件夹；任何文件夹都不能嵌套，搜索期间禁用拖放。菜单同时提供移动和前后排序。Private 转公开需确认，非空分组/文件夹删除可选择迁移/安全移出或一并删除。

**应用到草稿**只修改本页内存；有修改才显示**保存到云端 / 放弃修改**。两页各自拥有草稿，不影响另一页和原生收藏菜单。关闭未应用输入、切站、退出或清缓存涉及丢弃时确认；离线/会话失效保留草稿但禁改禁存。冲突保留草稿、不自动重试、不回退全量覆盖。静态源/无 KV 时主页只读，首次初始化只能在管理页确认。

- **书签管理** 打开/复用原 `home.html`：Raindrop 收藏集/列表/编辑面板为基准的固定浅色界面。左侧分组筛选，中间列表（默认，可切换网格），右侧书签编辑面板；窄屏面板全宽。分组操作收进菜单，书签操作支持鼠标和键盘。
- 面板的 **应用到草稿** 不会直接保存到云端；有修改才显示 **保存到云端 / 放弃修改**。未应用输入关闭前确认。两页独立标签页，打开或复用另一页不丢弃管理页草稿。
- 主页、管理页、右键菜单共用按站点隔离的已确认 IndexedDB 缓存。两页内存草稿互不传播，也不影响原生收藏菜单；保存/右键收藏成功后自动更新。退出不删除 Private 本机副本，清除入口在右上角账户菜单内。
- 不替换浏览器新标签页，不增加权限、主题切换器或第三方运行时，不新增 API。仅精确可信 `start.html` / `home.html` 可请求 `save`，服务器重新鉴权并检查源/版本；主页不能调用静态初始化，popup、查询参数伪装页及内容脚本不可写；普通网页和内容脚本仍不能读取完整缓存。
- 所有界面代码/字体本地提供；Fjalla One 字体的 SIL OFL 许可随 `fonts/OFL.txt` 分发。主页使用系统字体，未复制 iTab/Raindrop 的应用源码、商标或品牌素材。设计基准在仓库根目录 `DESIGN.md`，研究截图和合成测试产物不发布。

`npm run test:extension` 包含真实 MV3 双页面测试、320/390px 布局、子卡片搜索、草稿隔离、编辑防丢失、页面/操作白名单及缓存联动。原生右键菜单和站点授权气泡仍需人工验收。
