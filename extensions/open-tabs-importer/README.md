# 栖页 · 书签桌面

Qiye — Bookmark Desktop，单一内置主页 start.html。不接管新标签页、不读取 Chrome 收藏夹。新版连接 SmartTools v2 书签服务；旧网站协议不再作为扩展保存的后备入口。Manifest 版本仍为 1.2.0，业务文档 schemaVersion 为 2，两者含义不同。

## 安装与连接

1. 服务端先完成经授权的维护迁移并启用 BOOKMARKS_MODE=v2；参阅仓库 BOOKMARKS_V2.md。未初始化/未启用时扩展明确报错，不自行创建空库或覆盖旧 KV。
2. 开发者模式加载本目录；脚本、样式、图标和字体均本地打包。
3. 主页右上角账户 → 高级设置，填写服务端地址并点击保存；先申请该 origin 权限，通过才保存。拒绝保留原设置。
4. 使用现有管理员账号登录；HTTP(S) Cookie 由浏览器管理，生产要求 HTTPS。登录不需要新账号或长期 Token。

## 浏览与编辑

根文件夹显示为分类，内部文件夹可多层嵌套（总深度最多32）。逐层打开、面包屑返回；搜索标题、地址、描述、备注并显示完整路径。Private 向后代继承；隐藏项默认不展示，分类/空白菜单可开启整理隐藏项。

右键、可见更多按钮或键盘菜单进行新增/编辑/删除/移动；左键拖动排序、移入文件夹或移出到分类。移动菜单支持文件夹成为根分类；不可移入自己/后代。Private 转公开或解除继承保护须确认。删除非空容器选择迁移内容或全部删除。特殊旧节点只读保留，可导出原始节点或删除。

修改先“应用到草稿”，再“保存到云端”。每个主页的草稿独立，未保存不污染缓存和右键菜单。保存使用同一 v2 文档与 baseEtag；冲突保留草稿，不自动重试或退回旧保存接口。只有已登录、站点已授权、已加载可写版本且连接正常时才能编辑。失败不伪装成退出；401 才撤销会话状态。

顶部 updatedAt 只来自服务端确认；账户缓存信息同时区分云端更新时间与本机同步时间。无变化保存不更新时间。云端成功但缓存失败会明确提示，勿直接重复提交。KV 最终一致，不提供原子并发保护，应避免同时保存。

## 长期本机缓存

扩展自身 IndexedDB 按站点保存完整确认文档，含 Private，不加密、无主动过期、不会随浏览器账号同步。退出、会话失效、离线或权限撤销仍可只读查看。服务器不能撤回已下载副本。主页及原生右键菜单共用确认缓存，各页草稿仅在内存。

原数据库升级而不改名。旧 sections 快照可只读转换浏览，不自动上传；成功获取 v2 后原子替换该站点旧快照。损坏/写入失败保留旧缓存并提示。清除当前/全部站点缓存也会通知其他主页丢弃相关内存数据；退出与清缓存独立，共用设备应两者都做。密码与 Cookie token 不写入存储。

## 浏览器右键收藏

网页/链接/扩展图标 → 收藏到栖页 → 分类/多层文件夹 → 收藏到此处。无缓存时提示登录/加载；有缓存时未登录也显示目的地。真正收藏重新鉴权、读最新文档、按稳定 ID 核对有效 Private 状态、检查同位置完整 URL 重复、携带最新 baseEtag 保存。目标消失/隐私变化/冲突不重试。角标与弹窗显示结果。超过200容器或浏览器菜单限制时使用主页手动添加入口。

## 标签采集暂缓

当前页、当前窗口、全部窗口的原采集代码及复制/导出不重做、不迁移。旧网站确认导入按钮暂时隐藏禁用，新版采集导入后续另议；原内容脚本和相关权限暂保留。弹窗可打开主页或服务端账户配置说明页。网站 v2 模式不再提供书签后台；备份安装/恢复由维护人员另行核对处理，不引导用户到已退休后台。

## 权限与账户

保留 tabs、scripting、storage、contextMenus 及按需站点访问权限，无新增权限。普通网页/内容脚本不能读取完整缓存；popup 不能保存；带 query/hash 的伪装主页不能获取主页消息权限。账户登录使用 /api/v2/auth/login、/api/v2/auth/session、/api/v2/auth/logout；原 /api/account/* 已停用（410），/api/change-password 继续 404。修改密码需更新 Pages 环境 Secret PASSWORD 并重新部署；若未设置 PASSWORD，生产将回退到公开默认密码，登录后显示警告。旧 ADMIN_* 和 KV 自定义密码均不会用于 v2。

Cookie 策略阻止登录时请检查站点授权/浏览器策略；网站登录不保证绕过扩展 Cookie 限制，不降低 Cookie 安全属性。

## 本地验收

npm run test:extension 覆盖真实加载 MV3、多主页冲突、长缓存/重启/退出/离线、菜单收藏、拖放、响应式及消息白名单；合成 loopback 站点在临时 manifest 预授权，不访问生产。原生菜单显示、权限气泡/撤销、严格第三方 Cookie 策略仍需人工验证。npm run test:v2 覆盖模型/API和旧网站退休后的暖缓存升级。

## 拖动侧栏调宽

- 桌面默认 180px，拖动右边界可在 56px 与 min(280px, 窗口宽度的 35%) 之间调整；小于 128px 为图标在上、名称在下，达到 128px 自动切为横向分类列表。长名称省略，悬停查看全名。
- 分隔条热区为 8px；双击恢复默认。键盘聚焦后，左右键调整 8px，Shift + 左右键调整 24px，Home/End 到最小/最大。Escape、指针取消或窗口失焦取消当前拖动。
- 宽度 ≤600px 时继续使用分类抽屉，宽度为 min(240px, 100vw - 48px)，不覆盖桌面偏好。窗口变窄只临时限制实际宽度，变宽后恢复。
- 本机自动记住宽度，所有站点通用，多个主页同步；本页拖动不会被其他主页打断，确认采用本次值，取消采用最新已保存值。退出、切换站点和清除书签缓存不重置宽度。
- 无需登录、不产生书签草稿、不写入 IndexedDB、不上传服务器。拖动结束才保存，键盘连续调整合并写入；存储失败保留当前页面宽度并提示“宽度未能记住”。

## 主页 JSON 导入与导出

右上角管理员／账户菜单的“书签备份”中提供“导出 JSON”和“导入 JSON”，不新增扩展权限。

- **导出**：下载 `qiye-bookmarks-时间.json`，内容为当前站点最近确认的 `{schemaVersion:2, updatedAt, roots}` 文档；包括全部层级、隐藏项、Private 及保留字段，不包括当前页未保存修改、缓存外壳或凭据。存在有效 v2 缓存时，离线／退出后仍可导出；旧版只读缓存不提供此文档导出。导出前提示文件未加密，请妥善保管。
- **导入**：仅支持 `.json` 完整 v2 业务文档，最大 20 MiB。不接受 `sections`、JavaScript 源码、单节点导出或 `{document, etag}` 等存储/API 外壳；不执行文件中的代码。
- **校验**：检查 JSON 语法、schemaVersion、顶层更新时间、roots、节点类型及必填字段、全文档 ID 唯一性、最多 32 层、安全链接和已有模型规则；拒绝节点级 updatedAt。校验失败、读取失败或取消均保留现有草稿及缓存。
- **应用**：登录并加载可写云端版本后才能导入。校验通过会列出数量并确认**替换当前页全部书签与未保存修改，不合并**；空文档额外提示清空风险，Private/隐藏状态以文件为准。
- **保存**：导入仅形成本页草稿，不影响其他页面或右键菜单。保留本页当前 ETag 和基准 updatedAt，不采用文件时间伪造云端更新时间；点击“保存到云端”仍需鉴权和冲突检查，成功后才更新确认缓存。同内容导入无需保存。读取文件期间站点、数据或会话发生变化时取消导入。
- 导出的文件是独立副本，退出、清缓存或卸载扩展不会代为删除下载文件；需自行保管、删除。

## 服务端账户配置

默认账号 `admin`、默认密码 `codingriver2026` 是公开的不安全凭据；请在 Pages 生产环境配置独立 `PASSWORD` Secret 和至少 16 字符的独立 `AUTH_SECRET`，可通过 `USER` 覆盖账号。缺失 PASSWORD 会启用公开默认密码；显式设置为空会拒绝登录。更改配置并重新部署后旧会话在新实例失效，扩展需重新登录；本机 Private 缓存不会因退出或改密自动清除。`/account.html` 是静态配置说明，不提供在线修改密码。
