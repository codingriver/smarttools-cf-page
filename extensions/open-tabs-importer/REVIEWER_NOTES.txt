Qiye — Bookmark Desktop 1.2.0 | Reviewer Notes

Standalone extension for a self-hosted Cloudflare Pages v2 API; there is no companion website frontend. Test with an isolated v2 server and synthetic KV document. Open start.html, grant access to that server origin in Advanced Settings and sign in. The default server PASSWORD is public and must be changed in production. Only the five v2 routes are supported; old routes and pages return JSON 404.

Permissions: tabs, storage, contextMenus; optional host permission requested only for configured origin. No scripting/content script, cookie access, native bookmarks, history or new-tab override. Popup copies/exports open tabs as text/HTML/JSON; there is no website handoff. Native right-click capture checks auth, destination identity and ETag again on write. Exact start.html sender whitelist protects saves and full-cache reads from popup/content scripts/websites.

Full administrator v2 data, including Private, stays in extension IndexedDB without expiry or encryption. It remains readable after logout/offline/site permission revocation until independently cleared. JSON export/download may also contain Private; imported JSON must validate v2 structure and becomes a local draft until explicit save. The cloud keeps only the current document; no server backup or restore. Existing old v1 snapshots are ignored and removed when clearing cache; v2 legacy special nodes stay read-only.

Test `npm run test:extension` for a real unpacked extension against a loopback synthetic API. Test actual native context menus, browser permission prompts, third-party cookie policies, and images separately with synthetic data; automation does not certify those browser surfaces or real KV propagation. No production Private data in test fixtures.
