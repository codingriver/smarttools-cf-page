Privacy Policy — Qiye — Bookmark Desktop

Qiye (栖页) retains tab collection/copy/export and provides a built-in bookmark desktop for your own SmartTools bookmarks. It does not replace the new-tab page or manage Chrome's native bookmarks.

Data processed

  • When you use the context menu: the chosen page/link URL and page title are sent to your configured SmartTools server after authentication. Existing cached destination names, including Private, appear in menus.
  • When you collect, copy or export tabs: tab titles, HTTP(S) URLs and favicon URLs.
  • When you sign in: the administrator username and password you enter are sent only to your configured SmartTools site's login endpoint over HTTPS (local HTTP is allowed for development).
  • When browsing or editing: that site's recursive bookmark/container data, including inherited Private content for an authenticated administrator. Cloud saves write to your own SmartTools server using the authenticated v2 protocol; only its confirmed document updates the shared cache. The document has one cloud update timestamp; local cache write time is separate.

Browser storage

The configured site URL is stored in chrome.storage.sync and may synchronize with your browser account if browser sync is enabled. The last selected group key per site and the desktop sidebar width (desktopSidebarWidth, shared across sites) are local interface preferences in chrome.storage.local, not bookmark content. The width is not uploaded to the server or saved in the bookmark cache; logout and bookmark-cache clearing do not reset it. Pending tab imports are temporarily stored in chrome.storage.local until the website acknowledges them. Complete administrator bookmarks, including Private, are stored per site in extension-origin IndexedDB and shared by the homepage and context menus. There is no proactive expiry or browser-account synchronization of this cache; it is not encrypted. Logout, session expiry, offline use and permission revocation retain a readable local copy, which the server cannot revoke. Separate current-site/all-sites clear controls erase cached data and affected open-page drafts. Uninstalling, browser cleanup or storage failure can lose this cache. Passwords and Cookie tokens are never persisted; unsaved drafts remain in each page’s memory.

The browser manages the site's HttpOnly, Secure, SameSite=Strict login cookie. The extension cannot read that cookie and has no cookies permission. Logout affects that site's session in the same browser profile. Private is server-side access control, not encryption.

JSON bookmark files

At your request, the account menu downloads the last confirmed bookmark document as a JSON file, including hidden and Private content, without unsaved drafts, cache metadata or credentials. This file is not encrypted and remains outside the extension cache; logging out, clearing cache or uninstalling does not delete your downloaded copies. Keep or delete them yourself. JSON imports are validated locally, require a writable administrator session and become a replacement in-memory draft only after confirmation. They are sent to your configured server only when you explicitly save to the cloud; ordinary bookmark image requests still apply when rendering imported data.

Site access and network requests

The extension requests access to the site you configure, on demand. It no longer requires an all-sites grant or injects a script into every webpage. Management API requests go to the configured SmartTools site. The retained legacy import script is restricted to its configuration page; website-confirmation import buttons are disabled in this version. No new collection permission is added.

Bookmark images can load from the image hosts specified in your bookmark data; those hosts receive ordinary image requests. Opening a bookmark contacts its destination. No analytics, tracking or advertising service is included.

Your controls

You can revoke site permission or uninstall the extension in browser settings. Logout, detected session expiry and permission revocation revoke cloud write access, not local viewing. On shared devices, log out AND use the homepage’s separate clear-cache controls. Clearing cache alone does not end your server session; a later authenticated refresh can download it again. Unsaved edits are discarded when the page closes. Remove any undelivered pending imports by clearing extension storage. Deleting the extension does not delete bookmarks already saved on your SmartTools server.

Contact

Please open an issue in the SmartTools project repository for questions about this policy. Do not include passwords, cookies or Private data in reports.

Last updated: September 29, 2026

Administrator sign-in uses the configured site’s v2 authentication API and a browser-managed secure Cookie. Online password changes, recovery, and global session revocation are not supported. Update the server PASSWORD Secret and redeploy to change the password. If PASSWORD is absent, the server uses a publicly known default password and warns signed-in users; configure a unique secret before public use. Logging out or changing credentials does not erase previously cached Private bookmarks.
