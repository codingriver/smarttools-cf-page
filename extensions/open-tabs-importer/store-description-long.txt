Qiye — Bookmark Desktop (栖页 · 书签桌面)

A bookmark desktop for your own SmartTools v2 server, with categories, nested folders and explicit cloud saves. It does not replace your browser's new-tab page.

Features
- Search and organize bookmarks in a standard icon desktop. Drag or use menus to move/reorder items; folders can nest, with cycle/depth protection.
- Root categories and folders share stable identity, visibility and inherited Private settings. Show hidden items when organizing.
- Sign in using your existing administrator account; saves require server authentication and version checks. Each homepage has its own unsaved draft.
- Right-click a page, link or toolbar icon to save into a cached container. Same-location duplicate URLs are skipped; changed destinations require review.
- Shared long-lived local cache, including Private, readable offline and after logout; separate current-site/all-sites clear controls.
- Keep unsupported legacy content read-only for inspection/export or explicit deletion rather than silently losing fields.
- Retain current-page/current-window/all-window tab collection, clipboard and HTML/JSON export. Old website-confirmation import is deferred and its buttons disabled in this version.

Setup
Configure your HTTPS service address and approve that origin, then sign in. Requires the new /api/v2/bookmarks protocol and separately prepared v2 server data; no automatic online migration or legacy-write fallback. The website account page is a static server-configuration guide; password changes are made by updating the server PASSWORD Secret and redeploying. A missing PASSWORD enables an insecure public default and is flagged when signed in. Old account protocols are retired.

Privacy and permissions
Required permissions remain tabs, scripting, storage and contextMenus; site permissions are optional and requested on demand. No Chrome bookmarks/history/cookies access, analytics or new-tab override. Passwords and Cookie tokens are not stored by the extension. Your configured URL may sync with your browser account; bookmark cache and interface preferences do not.

Full cached data, including Private, stays in this extension's IndexedDB without proactive expiry. It is not encrypted and remains readable after logout, expiry, offline use or permission revocation. On shared devices, log out AND clear local cache. Uninstall, browser cleanup and storage failure may remove the cache. Private means server access control, not encryption. Image hosts receive ordinary image requests; clicked bookmarks contact their destinations. KV version checks detect observed conflicts but do not provide atomic multi-client locking.
